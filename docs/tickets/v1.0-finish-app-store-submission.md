### Audit fixes shipped in build 3

- **C1 (critical):** `MDNSCache` ran `dscacheutil` via `Process()` on every poll
  for `.local` hosts — forbidden under the sandbox. Gated behind
  `#if !MODELSTATUS_APP_STORE`; the App Store binary verified free of the
  `dscacheutil` string. (~~`.local` users on the App Store build enter IPv4 directly.~~ **Wrong — corrected
  2026-09-09.** `.local` resolves fine in the signed sandboxed build: 45ms, verified
  against a raw-LAN-IP control. `dscacheutil` was only a cache/diagnostic; URLSession
  reaches mDNSResponder through ordinary DNS APIs, which `network.client` permits.
  See `v1.0-resubmit-2026-09.md`.)
- **C2 (critical):** `@_silgen_name("SecStaticCodeCreateWithPath")` private SPI in
  `Discovery.swift` — auto-rejection risk. Gated out; App Store binary verified
  free of the `SecStaticCode` symbol.
- **H3 (high):** `DiagnosticBundle` (sw_vers/sysctl/ps/zip subprocesses) compiled
  into the sandbox binary though the menu item was gated. Whole enum + AppDelegate
  handler now `#if !MODELSTATUS_APP_STORE`.
- Minor: added `privacy: .public` to `UpdateChecker` HTTP-status log.
- Verified: 118 tests pass in BOTH variants (default + `-DMODELSTATUS_APP_STORE`).

### Key finding — no provisioning profile needed

The 2026-06-01 `.pkg` that PASSED Apple's validation had **no embedded
`embedded.provisionprofile`** (confirmed by expanding `build/ModelStatus.pkg`).
A sandboxed app whose only entitlements are `app-sandbox` + `network.client` +
`files.user-selected.read-write` does not need one for the MAS upload. So the
resubmit recipe is profile-free, matching what Apple already accepted.
